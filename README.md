# James Dandridge Website

A static website for author James Dandridge, featuring the latest story and a simple contact form.

## Files

- `index.html` — landing page with the story reader and contact form.
- `about.html` — author bio page.
- `styles.css` — site styling.
- `script.js` — story loader and contact form behavior.
- `story.txt` — the text of the story for the home page.
- `cover.jpg` — book cover image.

## Deployment

This site can be hosted with GitHub Pages. After the repository is created and pushed, enable Pages in the repository settings and set the branch to `main`.
