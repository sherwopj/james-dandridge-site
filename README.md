# James Dandridge Website

A static pre-publication website for James Dandridge's debut novel, *Uncle Jimmy's Unified
Universal Theory of Everything*. The site shares the publisher synopsis, an excerpt from
Chapter One, the author bio, and a contact form for readers, reviewers, and literary agents
to follow the book toward publication.

## Files

- `index.html` — landing page with the synopsis, excerpt reader, and contact form.
- `about.html` — author bio page.
- `styles.css` — site styling.
- `script.js` — excerpt loader and contact form behaviour.
- `excerpt.txt` — the Chapter One excerpt shown on the home page.
- `cover.jpg` — the book's cover art, used on the home and about pages.
- `story.txt` — the full manuscript text. Not linked from the site (this is a
  pre-publication site, not the full book), kept as a working archive. Its
  encoding was previously corrupted (double-encoded UTF-8/CP1252) and has been
  repaired, but it still carries some stray line breaks from its original
  extraction and hasn't been fully cleaned up.

## Deployment

This site can be hosted with GitHub Pages. After the repository is created and pushed, enable Pages in the repository settings and set the branch to `main`.
